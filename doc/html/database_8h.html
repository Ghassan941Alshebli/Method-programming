Подробное описание

Объявления функций для управления базой данных пользователей.

Данный модуль предоставляет функции для инициализации базы данных SQLite, регистрации пользователей, их аутентификации и получения базовой информации.

Инициализирует подключение к базе данных и создаёт таблицу пользователей, если она не существует.

Открывает файл базы данных users.db. Если таблица users не существует, создаёт её со следующими полями: id, username, email, password.

Возвращает
true — если инициализация прошла успешно, false — в случае ошибки подключения или создания таблицы.
