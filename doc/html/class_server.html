Подробное описание

Класс сервера, обрабатывающего текстовые команды.

Управляет списком клиентов и обрабатывает их запросы.

Разбирает входящие запросы вида "КОМАНДА|арг1|арг2" и делегирует выполнение базе данных или заглушкам алгоритмов.
