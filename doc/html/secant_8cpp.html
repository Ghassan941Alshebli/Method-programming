◆ secantMethod()

double secantMethod ( double x0,
double x1 )

Применяет метод секущих для нахождения корня f(x) = 0.

Находит корень уравнения f(x) = 0 методом секущих.

Выполняет 10 итераций по формуле: x₂ = x₁ - f(x₁) * (x₁ - x₀) / (f(x₁) - f(x₀))

Аргументы
x0Первое начальное приближение.
x1Второе начальное приближение.
Возвращает
Приближённое значение корня после 10 итераций.
