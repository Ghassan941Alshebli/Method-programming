Подробное описание

Точка входа TCP-сервера на базе Qt.

Сервер принимает подключения клиентов, обрабатывает запросы через текстовый протокол с разделителем '|' и делегирует выполнение модулям: Database, Algorithms (MD5, Vigenere, Secant, Graph).

Функции

◆ handleRequest()

QString handleRequest ( const QString & request)

Разбирает и выполняет запрос клиента.

Поддерживаемые команды:

  • REGISTER_USER|username|email|password
  • LOGIN|email|password
  • MD5|text
  • VIGENERE|text|key
  • SECANT|x0|x1
  • GRAPH|edges

Точка входа приложения.
