\doxysubsection{Detailed Description}
Класс базы данных пользователей, реализованный как Singleton. 

Singleton-\/класс для хранения пользователей в памяти.

Гарантирует единственный экземпляр на всё время работы программы. Хранит список имён пользователей в оперативной памяти.

Хранит пары username → password в map. Поддерживает регистрацию и аутентификацию пользователей.
