\doxysubsection{Подробное описание}
Реализация функций управления базой данных пользователей. 

Использует Qt SQL с бэкендом SQLite для хранения и получения данных пользователей:\+ регистрации, аутентификации и поиска.

Инициализирует базу данных SQLite и создаёт таблицу пользователей. 

Инициализирует подключение к базе данных и создаёт таблицу пользователей, если она не существует.

Открывает файл базы данных {\ttfamily users.\+db}. Если таблица {\ttfamily users} не существует, создаёт её со следующими полями:\+ id, username, email, password.
