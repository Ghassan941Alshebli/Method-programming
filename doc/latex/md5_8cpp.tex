Вычисляет MD5-\/хэш входной строки. 

Генерирует MD5-\/хэш для переданной строки.

Преобразует строку в UTF-\/8, применяет алгоритм MD5 через QCryptographic\+Hash и возвращает результат в hex-\/формате.
