\doxysubsection{Detailed Description}
Точка входа TCP-\/сервера на базе Qt. 

Сервер принимает подключения клиентов, обрабатывает запросы через текстовый протокол с разделителем \textquotesingle{}\texorpdfstring{$\vert$}{|}\textquotesingle{} и делегирует выполнение модулям:\+ \doxylink{class_database}{Database}, Algorithms (MD5, Vigenere, Secant, Graph).
