\doxysubsection{Detailed Description}
Класс сервера, обрабатывающего текстовые команды. 

Управляет списком клиентов и обрабатывает их запросы.

Разбирает входящие запросы вида "{}КОМАНДА\texorpdfstring{$\vert$}{|}арг1\texorpdfstring{$\vert$}{|}арг2"{} и делегирует выполнение базе данных или заглушкам алгоритмов.
